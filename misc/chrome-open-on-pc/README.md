# Zhihu++ 在电脑打开（浏览器扩展）

点击浏览器工具栏中的扩展图标，直接打开 Zhihu++ 发送到电脑的最新一条内容。不需要先打开知乎收藏夹页面。

## 当前版本

**1.0.0**

扩展会随项目更新。如果 App 提示的版本与这里不一致，说明扩展不是最新版，请按下面的方式重新下载安装。

## 安装

需要先在浏览器中登录**与手机相同的知乎账号**。

1. 解压本目录的 `zhihu-plus-open-on-pc.zip`，得到一个包含 `manifest.json` 的文件夹。
2. 打开 Chrome 的 `chrome://extensions`（Edge 为 `edge://extensions`）。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择刚才解压出来的文件夹（不是 ZIP 文件本身）。
6. 点击浏览器工具栏的拼图图标，把「Zhihu++ 在电脑打开」固定到工具栏。扩展默认不会固定。

## 使用

1. 在 Zhihu++ 中点击「在电脑打开」，当前内容会加入私密收藏夹「Zhihu++: 要在浏览器中打开的内容」。
2. 确认浏览器登录的是与手机相同的知乎账号。
3. 点击浏览器工具栏中的扩展图标。
4. 扩展会自动打开收藏夹中最新的一条内容。

如果长时间没反应，请检查浏览器是否登录了与手机相同的知乎账号，然后重试。未登录、账号不同、还没有发送过内容或收藏夹为空时，弹窗也会给出对应提示。

## 更新

- 当前版本：**1.0.0**
- 下载新的 `zhihu-plus-open-on-pc.zip`，解压后重新“加载已解压的扩展程序”，或覆盖原文件夹后在扩展管理页点击“重新加载”。
- 扩展更新后如果行为异常，请先确认扩展版本与 App 提示的版本一致。
