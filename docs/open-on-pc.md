# 在电脑打开

Zhihu++ 的「在电脑打开」会把当前回答或文章加入私密收藏夹「Zhihu++: 要在浏览器中打开的内容」。电脑上的浏览器扩展读取这个收藏夹，点击扩展图标即可直接打开最新一条。

## 当前扩展版本

**1.0.0**

扩展会随项目更新。App 发送成功后会提示当前要求的扩展版本；如果和实际安装的版本不一致，请重新下载安装，旧版本可能无法正常使用。

## 下载与安装

扩展压缩包位于 [`misc/chrome-open-on-pc/zhihu-plus-open-on-pc.zip`](../misc/chrome-open-on-pc/zhihu-plus-open-on-pc.zip)。

安装前请先在浏览器中登录**与手机相同的知乎账号**。

1. 解压 `zhihu-plus-open-on-pc.zip`，得到一个包含 `manifest.json` 的文件夹。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的文件夹（不是 ZIP 文件本身）。
6. 点击浏览器工具栏的拼图图标，把「Zhihu++ 在电脑打开」固定到工具栏。扩展默认不会固定。

## 使用

1. 在 App 中点击「在电脑打开」。
2. 确认浏览器登录的是与手机相同的知乎账号。
3. 点击浏览器工具栏中的扩展图标，扩展会自动打开收藏夹中最新的一条。
4. 如果长时间没反应，请检查浏览器是否登录了与手机相同的知乎账号，然后重试。

## 更新

- 当前版本：**1.0.0**
- 下载新的 `zhihu-plus-open-on-pc.zip`，解压后重新加载，或覆盖原文件夹后在扩展管理页点击“重新加载”。
- 扩展更新后如果行为异常，请先确认扩展版本与 App 提示的版本一致。
