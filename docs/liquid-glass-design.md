# Liquid Glass 设计与验收

## 产品范围

这是 Android 的第二套完整视觉风格。Material 是默认风格；Android 13 及以上可以在外观设置选择 Liquid Glass，重启后生效。所有风格复用同一份账号、导航、业务数据、阅读位置与偏好，不另建页面副本。风格开关不修改 Material 动态色、自定义背景或信息流布局偏好。

AndroidLiquidGlass / Backdrop 提供真实内容采样、模糊和折射，依赖仅进入 Android。平台支持声明负责控制入口；其他平台不伪装成已支持。选用 1.0.6 的 Android 发布版本，避免因视觉功能升级整个项目的 Compose 运行时。

## 视觉规范

- 内容与操作分层：正文、信息流、评论和输入表单使用稳定、可读的实体表面；导航、浮动操作使用玻璃。不会把所有卡片变透明。
- 浅色为雾白画布与白色内容面，深色为石墨画布与深灰内容面。蓝色用于导航选中与主要动作，绿色用于开关；错误与删除继续使用明确的警示色。
- 标题依靠字号与字重形成层级，中文使用系统字体和紧凑字距。正文不压缩既有用户字号、行距设置。
- 悬浮导航采用胶囊轮廓；内容卡片、设置分组、弹层分别采用适合其尺寸的圆角。点击目标至少保持 48 dp，文字缩放不能造成操作消失。
- 滚动时玻璃采样实际内容，不放装饰壁纸冒充背景。内容录制与玻璃绘制分离，禁止玻璃递归采样自身。
- 按压反馈短促、克制，滚动不驱动无意义的光晕或视差；系统关闭动画时控件仍可操作。

## 实施边界

| 能力 | 责任位置 | 必须覆盖的状态 |
| --- | --- | --- |

| 内容与导航材质 | `AdaptiveScaffold.kt`、Android `LiquidGlass.android.kt` | 内容滚过顶底栏、无顶底栏、隐藏动画、系统栏与键盘 inset |

| 通用动作 | 公共按钮、图标按钮、FAB | 启用、禁用、选中、按压、图标与文字、危险操作 |
| 设置与表单 | `SettingItem.kt`、开关、输入框、滑杆 | 分组、禁用、焦点、错误、键盘、长说明 |

## 页面验收矩阵

实现代码覆盖不能代替真实页面验收。每一项记录实际运行结果；没有进入目标页面就保持未验收。

- 首页：搜索入口、通知、信息流、主导航、创建与刷新动作。
- 关注与动态：顶部切换、列表、水平滑动和底部导航。
- 热榜、日报、历史、收藏：不同内容密度、图片、空态、加载与菜单。
- 搜索：输入焦点、键盘、搜索结果类型切换、历史及结果卡片。
- 问题、回答、文章、想法：阅读顶底栏、长正文、图片、投票、收藏、分享。
- 评论：列表、回复输入、键盘、返回、滚动位置与弹层边界。
- 用户与话题：展开/收起头部、关注等动作、标签切换和列表。
- 账号与全部设置：分组、开关、选择器、滑杆、对话框、输入与长标题。
- 通知与私聊：未读状态、列表、消息输入及键盘。
- 创作与登录：表单、提交/取消动作和错误提示；视觉验证不得发送内容或修改账号状态。

每类至少检查浅色与深色；关键内容页需检查滚动前后。风格切换要通过真实设置入口保存，再重启读回。截图应注明页面与状态，并配合语义树检查操作目标。

## 官方 catalog 复用与首个手机测试里程碑

来源为 AndroidLiquidGlass 1.0.6，commit `896a94a3ade1cc1a940b92365f942a34971fecda`。Maven 提供 Backdrop 特效；高层组件按官方 README 从 catalog 原样编译，见 `third_party/android-liquid-glass/README.md` 与 `SHA256SUMS`。

| 官方组件 | 应用接入 |
| --- | --- |
| LiquidBottomTabs + LiquidBottomTab | 全部主导航项，直接保留官方按住拖动、折射、膨胀与回弹 |
| LiquidButton | 公共 Button、Tonal、Outlined、TextButton 和 FAB，包括页面、弹窗及创作操作 |
| LiquidToggle | 设置开关，外层补充禁用、无障碍及父设置行事件适配 |
| LiquidSlider | 公共设置滑杆、阅读播放器及独立视频进度；外层补充离散步长、结束回调与无障碍 |

catalog 没有提供输入框、复选框、菜单、工具栏或弹层。这些按视觉体系适配已有组件；没有自行重写以上五个官方组件。Material 分支继续使用原控件。

首轮证据保存在 `/tmp/zhihu-glass-evidence/`：官方底栏四秒连续拖动的视频 `catalog-tabs-drag.mp4` 与中间形变帧 `catalog-tabs-drag-mid.png`，拖动从首页到账号并验证最终页面；官方设置开关点击及反向拖动、滑杆透明度 100%→80%→100%；真实设置入口选择 Material 后重启，导航恢复 Material，再选择 Liquid Glass 并重启安装最终包。所有八份上游源码 SHA256 一致。构建 `:app:assembleLiteDebug`、`:shared:compileKotlinJvm`、`:shared:ktlintCheck`、`:app:ktlintCheck` 通过。

这是用户要求先提交并在手机测试的组件替换里程碑，不代表整个页面验收矩阵全部完成。之前已检查首页、关注、日报、历史、账号、收藏、文章、评论及键盘等页面；官方组件替换后仍需逐页复核。后续重点：大字号、个人页折叠、搜索/创作/通知/私聊、视频真实播放、禁用与无障碍、开关在父列表滚动取消时的行为、各类浮动操作的碰撞与层次、性能。

## 后续验收：2026-09-06 05:21 起
